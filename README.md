# GST 2B vs Books Reconciliation Tool

This is a web-based GST reconciliation tool built using Python and Streamlit.

## Features

* Upload Purchase Register Excel
* Upload GSTR-2B Excel
* Automatic invoice matching
* Detect missing ITC
* Vendor mismatch detection
* Download reconciliation report


## Use Case

This tool helps Chartered Accountants and businesses quickly reconcile:

* GSTR-2B
* Purchase register
* ITC claims
